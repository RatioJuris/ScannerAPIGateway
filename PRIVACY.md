# Privacy Policy — Scanner API Gateway

**Effective date:** October 21, 2026  
**Application:** Scanner API Gateway  
**Developer:** RatioJuris

## 1. Introduction

Scanner API Gateway is a Windows command-line utility that provides a unified interface for scanning documents using Windows Image Acquisition (WIA), TWAIN, and network eSCL/AirScan-compatible scanners.

This Privacy Policy explains how the application is intended to handle information when you use it.

## 2. Scanned Documents and Files

The application allows users to initiate scans and specify where the resulting image files are saved.

Scanned documents may contain personal, confidential, or other sensitive information. Users are responsible for selecting appropriate storage locations and protecting the resulting files.

## 3. Local Processing and Scanner Communications

The application communicates with scanners through the supported scanner interfaces and drivers. Network scanners may communicate over the local network.

The application may interact with scanner drivers, operating-system services, and scanner hardware to perform requested operations.

The precise data transmitted to scanners or other components depends on the selected scanner, driver, configuration, and scanning operation.

## 4. Information Collection

The application's documented functionality does not require users to create an application account.

This section must be updated to accurately disclose any telemetry, diagnostic information, usage analytics, or other information collected by the implemented application and its dependencies.

## 5. Third-Party Components

The application relies on supported Windows scanner interfaces and may use third-party scanner drivers or components.

Those components may be subject to their own privacy policies and data-handling practices. Users should consult the relevant providers for further information.

## 6. Data Security

Users should protect scanned files and any sensitive information processed through their scanners. Appropriate device security, access controls, and secure storage practices are recommended.

No software or storage system can be guaranteed to be completely secure.

## 7. Children's Privacy

Scanner API Gateway is a general-purpose utility and is not specifically directed at children.

This Privacy Policy may be updated when the application's functionality or data-handling practices change. The latest version will be published in the application's official repository.
