Bridge Modern Web Apps with Local Hardware Scanners

ScannerAPIGateway is a lightweight, cross-platform REST & WebSocket API daemon developed by RatioJuris. It exposes USB, SCSI, and network document scanners (TWAIN, WIA, SANE, eSCL) through a secure localhost interface—eliminating legacy browser plugins, ActiveX, and proprietary SDK lock-in.

Core Capabilities

Engineered for High-Volume Document Workflows

Designed for legal tech, healthcare records, banking, and archival web systems that need deterministic, low-latency control over physical sheetfed and flatbed scanners.

Unified Multi-Driver Abstraction

Write once against a clean JSON schema while the gateway translates instructions to Windows TWAIN/WIA, Linux SANE, or network AirScan (eSCL) hardware drivers.

Real-Time WebSocket Page Streaming

Receive instant page-by-page binary frames, ADF paper-jam alerts, feeder empty states, and progress telemetry over /ws/v1/events.

Duplex, Blank-Page Skip & PDF/A

Full hardware parameter control: 100–1200 DPI, Simplex/Duplex ADF, Auto-Deskew, Blank Page Thresholding, and multi-page PDF/A-2b, TIFF, or PNG output.

Binary Integrity & Certificate Authority Verification

Why Code Signing & Local Hardware Trust Matter

Because modern web browsers sandbox direct USB and kernel driver access for security, ScannerAPIGateway operates as a trusted local background service. Cryptographic code signing guarantees binary authenticity from build pipeline to end-user workstation.

Inspect GitHub Actions Build Provenance

1. Native OS Hardware Driver Invocation (TWAIN / WIA / SANE)

To communicate with physical imaging devices, the gateway executable (scanner-api-gateway.exe on Windows, scanner-api-gatewayd on Linux) loads native dynamic libraries (twaindsm.dll, Windows wiaacmgr COM interfaces, and libsane.so). Operating systems and enterprise Endpoint Detection & Response (EDR) suites require valid Authenticode / X.509 digital signatures before permitting a service binary to enumerate hardware buses or register as an OS service.

2. Localhost Loopback Binding & Windows SmartScreen Compliance

The gateway binds strictly to the local loopback interface (127.0.0.1:8443) and enforces strict CORS allowlists and token authentication. Signing the Windows Installer (.msi / .exe) prevents false-positive Windows Defender SmartScreen warnings and ensures users never have to bypass OS security prompts to install open-source software.

3. Reproducible Builds & Public Signing Policy

All official release binaries are built exclusively from public tags in github.com/RatioJuris/ScannerAPIGateway via automated GitHub Actions workflows. No proprietary blobs, telemetry agents, or third-party adware are ever bundled. Every release publishes deterministic SHA-256 digests and build logs.
